# OpenGenieMaster

面向机器人任务执行、反馈和持续改进的独立开源具身 Agent 项目。

当前处于调研与项目初始化阶段，仓库包含调研文档和开发方向，尚无可运行的 Agent、仿真程序或机器人控制代码。

## 项目定位

以智元 Genie Master 的公开资料为研究对象，探索可复现、可扩展的具身 Agent 执行与学习闭环。本项目由社区独立维护，与智元 / AGIBOT 无隶属或官方合作关系。

## 拟开展的工作

- 任务执行：将任务拆解为可观测、可中断的技能调用。
- 执行反馈：记录观测、动作、结果和失败原因，形成可回放的任务记录。
- 经验管理：保存经验与策略版本，支持比较、回归评估和回滚。
- 仿真验证：先在受控仿真任务中检验执行与改进闭环。
- 机器人接入：在前述能力完成后，再接入明确约束的真机适配器。

以上是本项目的开发设想，不代表 Genie Master 已公开的实现或本仓库已有的功能。接口兼容性须以实际公开规范及验证结果为准。
