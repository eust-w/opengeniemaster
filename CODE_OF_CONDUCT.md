# Code of Conduct

> 中文：本项目采用《贡献者公约》（Contributor Covenant）2.1 版。违反行为准则的情况，请通过下文的 GitHub 私密渠道报告。

## Our pledge

OpenGenieMaster adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as its code of conduct. Read the full text at that link.

We pledge to make participation in this project a harassment-free experience for everyone, whatever their background or identity. We act and interact in ways that contribute to an open, welcoming, diverse, inclusive, and healthy community.

## Scope

This code of conduct applies in every project space, including issues, pull requests, reviews, and discussions. It also applies when someone represents the project in public spaces.

## Reporting

Report unacceptable behaviour privately through GitHub's private reporting form:

<https://github.com/eust-w/opengeniemaster/security/advisories/new>

Start the title with "Code of Conduct:". The form is the project's private channel for both security and conduct reports, and only the reporter and the maintainers can see a report. Maintainers review every report promptly and fairly, and keep the reporter's identity and the details confidential.

## Enforcement

Maintainers follow the Contributor Covenant's enforcement guidelines. The consequences escalate from a private correction, to a warning, to a temporary ban, to a permanent ban, depending on the impact of the behaviour.

## Attribution

This code of conduct is adapted from the [Contributor Covenant](https://www.contributor-covenant.org), version 2.1.
