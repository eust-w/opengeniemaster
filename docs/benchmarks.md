# 仿真评测

本文记录 `ogm bench --experiment all` 的结果，仿真种子固定为 0，可完全复现：

```bash
ogm bench --experiment all --out results
```

完整 JSON 含逐次试验明细，写在 `results/` 目录下（已加入 .gitignore）。

> **请先读这一段。** 所有数字都来自本仓库的语义仿真器（`opengeniemaster/sim/`）。仿真器不模拟物理：每个技能按公开写明的概率模型（[sim/policy.py](../opengeniemaster/sim/policy.py)）成功或失败，概率取决于请求带了哪些引导、用了哪个相机、是否涉及相似品或新品、机器人有哪些特性。这些参数是**假设**，用来让 GenieMaster 描述的失败机制在仿真中真实存在：遮挡的小挂钩、相似商品、新品、回撤时夹爪松开、有人闯入工作区、动作服务宕机、远距离判据误判。评测检验的是 Harness 能否按设计**利用**这些机制，即多模态引导、判据、恢复、连续性、多机派工和记忆。它不证明真机性能，也**不能与论文的真机数字比较**。

## 方法

| 方法 | 编码 Agent 配置 |
| --- | --- |
| 端到端 VLA | 每一步只给策略整体目标（`options.end_to_end`，每步额外 10% 偏离概率）；无观测、无判据、无恢复、单机器人；失败后继续执行 |
| 双系统 | 规划器按工作流分解子任务，只用语言引导；信任策略自报结果，失败重试一次，单机器人 |
| OGM（无记忆） | 本仓库 Harness：参考图、目标框、放置点、细粒度语言；判据 + 恢复预案 + 收尾近距离复核；连续性与多机器人派工；不读长期记忆 |
| OGM | 同上，并读取在 10 次预热试验（独立种子）中经反思与准入积累的长期记忆；评测期间记忆冻结 |
| Oracle 编排 | Harness 加上仿真真值（真实位置、遮挡、手臂分工、需要暂停的时机），作为上限参考，对应论文中的人工编排 |

指标：成功率 SR（全部目标达成）和任务完成度 TC（达成目标的比例），均对照仿真真值判定，不使用 Agent 的自我评估。每个任务、每个方法 100 次随机布局的试验。

每次试验的平均耗时与恢复次数：

| 任务 | OGM（无记忆） | OGM | Oracle 编排 |
|---|---|---|---|
| 招待客人 | 79 s · 2.7 次 | 65 s · 1.8 次 | 74 s · 1.2 次 |
| 铺桌布 | 93 s · 0.9 次 | 93 s · 0.9 次 | 90 s · 0.3 次 |
| 办公用品搜寻 | 145 s · 2.9 次 | 126 s · 1.5 次 | 118 s · 1.2 次 |
| 取货交付 | 66 s · 1.6 次 | 59 s · 1.3 次 | 70 s · 1.0 次 |
| 补货上架 | 99 s · 3.3 次 | 84 s · 2.2 次 | 93 s · 1.4 次 |
| 清洁 | 126 s · 3.4 次 | 126 s · 3.4 次 | 133 s · 1.5 次 |

解读：

- 基线的主要失败来自：仅凭语言分不清相似商品、认不出新品、看不清被遮挡的挂钩、夹爪在运输中松开、桌布铺不平（缺少手臂分工），以及无人复核导致的“自以为成功”。
- Harness 用参考图和目标框解决识别问题，用判据揭穿策略的误报，再用恢复动作补救（换腕部相机、放回错拿物体、回原地重新抓取、等待服务恢复）。
- 记忆的作用主要体现在“少走弯路”：补货平均耗时 99 s → 84 s，恢复次数 3.3 → 2.2；办公用品搜寻 145 s → 126 s。成功率提升集中在补货（78% → 87%）和办公用品（95% → 100%）。

换一组种子（`--seed 1000`，同样每任务每方法 100 次）时，平均 SR / TC 为：

| 端到端 VLA | 双系统 | OGM（无记忆） | OGM | Oracle 编排 |
| --- | --- | --- | --- | --- |
| 13.50 / 42.60 | 20.67 / 52.54 | 89.00 / 96.32 | 92.83 / 97.43 | 94.33 / 97.91 |

各方法的排序和差距不随种子变化；单个任务上的记忆收益在 0–9 个百分点之间波动。

## 实验二：能力组合（固定位置取货）

| 配置（逐级累加） | SR % | 每次试验恢复次数 |
|---|---|---|
| C1 arm IK | 52 | 2.06 |
| C2 + grasp planning | 62 | 1.74 |
| C3 + guidance-trained policy | 79 | 1.76 |
| C4 + object references | 89 | 1.33 |
| C5 + head/waist control | 99 | 0.95 |

C1/C2 只有 IK 和几何抓取规划，需要 Agent 提供目标框；C3 加入经引导训练的策略；C4 加入参考图条件；C5 加入头部 / 腰部主动感知，能看到货架后排的商品。

## 实验四：从经验中学习（办公用品搜寻，受限预算）

受限预算指每步最多尝试 2 次，且不允许整个工作项重做，用来衡量“第一次就做对”。对照组是同一 Harness 关闭记忆，在相同种子上运行；每轮结束后反思一次。

| 轮次 | 使用中的记忆条目 | SR %（记忆） | SR %（对照） | 恢复次数（记忆 / 对照） | 耗时 s（记忆 / 对照） |
|---|---|---|---|---|---|
| 1 | 0 | 60 | 60 | 2.5 / 2.5 | 104 / 104 |
| 2 | 3 | 60 | 30 | 1.8 / 2.9 | 101 / 105 |
| 3 | 6 | 100 | 60 | 1.1 / 2.6 | 78 / 98 |
| 4 | 7 | 80 | 30 | 0.8 / 2.9 | 83 / 110 |
| 5 | 7 | 90 | 50 | 1.3 / 3.2 | 95 / 121 |

最后一轮结束时的长期记忆：

- `[embodiment/guidance]` Keep the gripper closed during retraction and travel; release only at placement.（支持记录 21 条）
- `[embodiment/guidance]` For pick, the head camera cannot localize the target reliably; approach and localize with the wrist camera first.（支持记录 4 条）
- `[domain/criteria]` Verify place targets and results (near people, at a desk) at close range before declaring success.（支持记录 3 条）
- `[domain/guidance]` 'tissues-box' has repeatedly been found at cabinet; search there first.（支持记录 3 条）
- `[domain/criteria]` Verify search targets and results (with look-alike items) at close range before declaring success.（支持记录 5 条）
- `[domain/guidance]` 'earphone-case' has repeatedly been found at bar_counter; search there first.（支持记录 20 条）
- `[domain/safety]` Pause when a person or hand enters the workspace, then recheck before resuming.（支持记录 2 条）
- `[domain/guidance]` 'notebook-a5' has repeatedly been found at meeting_table; search there first.（支持记录 9 条）

这些条目与 GenieMaster 主页公开的办公用品案例同类：近距离核验边缘或不清楚的目标；耳机盒在吧台，不要拿附近相似的杂物代替；有人进入工作区时先暂停再复查；运输途中保持夹爪闭合、到位才释放。在本仓库中，它们由执行记录经反思自动得出，再经共享准入写入。

## 实验五：24 小时持续多机器人部署（便利店）

## 与论文的关系

论文报告的是真机结果。以 6 个真实任务、每方法每任务 100 次计，成功率为：端到端 VLA 18.83%，双系统 38.83%，GenieMaster 78.67%，人工编排 81.00%。其余公开结果：能力组合 C1 → C5 为 25% → 97%；1,000 SKU 时新品取货 92%，纯文本策略 20%；记忆 5 轮从 28.6% 升到 85.7%。本仓库的实验**沿用相同的实验设计**，但跑在仿真中，数值没有可比性，只有趋势方向可以参照。
